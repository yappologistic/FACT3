# Agent activity

While an agent is working, the activity pill above the message composer shows its current action
and the number of running sub-agents. Select the pill to inspect live activity without adding tool
rows to the conversation.

Use the selector at the top of the activity panel to switch between:

- **Tool calls** — commands, searches, file reads, and edits. Select a row to inspect the complete
  tool payload reported by the provider.
- **Sub-agents** — named sub-agents, their assignments, current state, and reported result.
- **Tasks** — the current plan, including completed, active, and pending steps.

When the turn finishes, the pill changes to a completed summary and stays available so you can
review the activity later. Activity detail depends on what the selected provider reports.
